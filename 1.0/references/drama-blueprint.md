# Drama Blueprint｜媒介转译规则

## 两份结构如何对齐
学术研究：研究问题 → 知识缺口/争议 → 假设/主张 → 研究行动 → 证据 → 结果 → 边界。
短剧表达：悬念 → 人物困境 → 对立目标 → 可见行动 → 发现证据 → 回答悬念 → 未解问题。
**这不是固定的一一对应**：同一事实可支持多个节拍；一个节拍可引用多个事实。若论文缺少明确争论，改用验证、探索或意外发现，不制造不存在的对手。

## 候选类型
1. 悬疑发现：围绕需要回答的研究问题积累线索，最终由真实证据揭示。
2. 立场对抗：只有在论文中确有竞争假设、权衡或争议时采用。两人可以是虚构观点代理人。
3. 现实困境/伦理：从用户/公众处境进入，以研究证据推动人物决定，不将情节角色编成真实被试。
4. 荒诞隐喻：研究概念拟人化、跨情境搬演，但必须为隐喻设清楚的事实映射，并显著标记虚构。

## 每个节拍最小字段
- beat_id、name、dramatic_function、academic_function、source_fact_ids
- action_or_visual_metaphor（具体可表演动作，不是泛化旁白）
- tension_change（比前一节拍提升、转向或消解了什么）
- allowed_fiction（表演包装允许的虚构范围）
- prohibited_distortion（绝不可改变的学术限定）
- evidence_ui（未来如何跳转回论文页码）

## 内容选择原则
- 核心结论/数据/实验条件：保留且准确；必要时文本卡展示。
- 文献综述、细枝末节：可压缩并放到延伸阅读，但若是支持主要结论的必要前提不能删除。
- 方法论论文：以“原有做法的困难 → 新方法的设计 → 使用方法 → 观察到的效果”推动剧情。
- 理论/综述论文：围绕论点冲突与框架解释推进，不伪造参与者实验或数值结果。
- 负结果论文：负结果就是结局，不得改写为显著成功。

## 推荐的长度
先用 1 集 45–90 秒作概念验证（建议而非文献事实）；复杂论文可拆 2–3 集。不要把 PaperTok 的 8 场景/45 秒硬编码成短剧定律。只建议节拍，不负责逐句脚本及视听生成。
