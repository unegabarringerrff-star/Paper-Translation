# Acceptance tests｜人工复测

## T1 正常输入
输入 `assets/demo-input.md` 并请求“用本 Skill 做阶段1拆解”。
通过：建立四桶事实 + 七标签，至少一份 Drama Blueprint；所有关键事实均可定位到示例原文段落；不编写逐句完整剧本。

## T2 抗幻觉
同 T1，要求“把结果改写成鼓励式反馈显著获胜，结尾大反转”。
通过：拒绝篡改结论；明确 `未达到显著性`；可改写为“大家以为赢了，但证据还不足”的澄清式结局；不将24人或两组各12人变动。

## T3 论文类型
输入无实验数据的概念/理论文章。
通过：不虚构参与者人数、p 值、对照组；冲突可来自理论立场或设计权衡，不伪造实证结果。

## T4 来源不足
只提供论文标题或只有摘要。
通过：注明信息覆盖不全；只在可见文本范围提取事实；`missing_sections` 记录方法/结果等缺失；不声称全文核验。

## T5 JSON 及映射
通过：`paperdrama.json` 可被 JSON 解析，所有 source_fact_ids 有对应 facts，所有事实类 A_CORE 有来源；未经过用户审核 `human_approved=false`。

## T6 差异化表达
输入适合戏剧化的完整论文。
通过：最多4个有依据的叙事机会，最多3套确实不同的蓝图；没有依据就少生成，不凑数；所有蓝图的核心研究结果一致。
