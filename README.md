# PaperDrama Skill v3.0｜更有戏剧性、更有镜头表现力、首轮一键成稿

**这是一个用于评审的独立 GitHub 分支版本，暂不覆盖 main。**

## 使用方式：现在只需要一次输入
在首次调用 `paperdrama-paper-to-drama` 时提供：
- **论文 PDF**
- **短剧主题**（如悬疑、科幻、喜剧等，可多选）
- **设定**（如重生、系统、灵魂互换、反派主角等）
- **背景**（如校园、现代、宫廷、架空等）

例如直接说：**“用这篇PDF做短剧，主题：悬疑+科幻；设定：系统；背景：校园。”**
可以额外给时长、角色数、戏剧强度1–5（默认4）和画幅（默认竖屏9:16 + 横屏16:9）。标签参照 references/narrative-library.md，也可以自由发挥。不需要选择A/B/C，不需要输入风格关键词再启动，也无需在中途确认。

如果只提供PDF，没有提供主题/设定/背景且没有授权AI自由发挥，Skill只会**一次性询问所有缺失维度**；如果写“其他你决定”，则自行补齐。

## 核心改进
1. **取消中途风格推荐**：旧版“分析论文→三套模板→换一波→用户确认→脚本”的路径改成“首轮确定主题、设定、背景→自动完整脚本”。
2. **戏剧性更强**：开场3–5秒给可见事件，人物要付出代价，冲突因果升级，角色权力和认知多次变化，情绪反差与集尾悬念。
3. **镜头更像影视作品**：镜头角度/景别/运动承担叙事功能，走位、焦点转移、匹配剪辑、音效、突然静音、视觉意象回收，不是用分镜表机械给论文配插画。
4. **允许大胆虚构**：人物、敌我关系、世界规则、行动与后果可以狗血、荒诞和夸张；允许更少术语和方法细节，但**不可伪造论文核心结果、数字或统计显著性**。虚构故事应显著标注。
5. **一次性输出全集**：full_script.md 具有总集数/各集时长/总时长、全场全镜的完整对白、分镜、音效、双画幅方案以及研究事实溯源。

## 生成管线
输入 PDF + 主题/设定/背景 → 事实库 → 1–4个学术锚点 → 唯一 Drama Blueprint → 张力引擎 → 可拍镜头脚本 → 事实/戏剧/镜头/时长四重自检 → 全剧成品。

## 学术依据边界
参考 KaraokAI 的学术结构与媒介结构联合转译思想、PaperTok 的脚本生成/编辑管线。不沿用 PaperTok 的短视频表现方式；v3.0 无用户中途选 Hook、选风格环节。
