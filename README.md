# PaperDrama｜论文到真人竖屏短剧场景生产包

PaperDrama 接收论文 PDF 与网页传入的故事背景、故事类型和戏剧强度，把论文的主要研究机制、发现或核心论证转成中文真人竖屏短剧，并交付按场景拆分的完整文本。MicroDrama 继续提取人物、拆分镜头并生成参考画面。

## 网页输入与默认行为

- 用户上传论文 PDF，即默认开始完整生成任务；无需再次输入“开始生成”或确认设置。
- 故事背景与故事类型由网页传入；未指定的项由系统结合论文自主补齐并记录假设。
- 受众：非本领域大学生，可覆盖。
- 语言：中文，可覆盖。
- 画幅：单一 9:16；其他画幅单独派生。
- 戏剧强度：4级强冲突短剧型，可选 1–5。
- 每集：60–180秒；集数根据故事完整性和因果推进自行决定。
- 交付：五份 UTF-8 TXT；03 是唯一默认下游输入。

## 风格参数

故事背景可为智能匹配、校园、职场、都市生活、家庭社区、乡村小镇、医疗机构、科研实验室、古装架空、近未来、星际未来、末世世界或奇幻世界。

故事类型可为智能匹配、正剧、悬疑、喜剧、情感、爱情、治愈、成长、励志、权谋、冒险或惊悚。背景和类型各自保持为一个主选项；特殊剧情装置由系统按需补齐，不作为必选风格。

## 五档强度

| 档位 | 重点 |
|---|---|
| 1 学术还原型 | 以可表演过程清楚呈现必要问题、方法、证据和局限。 |
| 2 轻度剧情型 | 用具体日常目标、人物反差和轻冲突帮助理解研究。 |
| 3 证据驱动型 | 让证据改变人物行动、关系或判断。 |
| 4 强冲突短剧型 | 每集尽快建立可回答的问题，让行动、反制、代价和回报持续推动故事。 |
| 5 极强戏剧型 | 用更尖锐且合理的选择与后果推进故事，核心发现或论证必须参与关键转折。 |

强度是完整预设，用户可明确覆盖其中一项，例如保持4级冲突但完整保留关键方法。强度提高不改变论文事实，也不允许牺牲角色动机与因果成立。

## 事实底线

论文数字、单位、组别、比较对象、结果方向、显著性、因果或相关性质、核心结论和必要限定必须准确。人物、关系、世界和事件可以虚构，但不能伪称论文实验、作者经历或研究已经证明虚构后果。

## 输出边界

交付五份 UTF-8 TXT。内容停在完整文本交接，不输出逐镜分镜、JSON、人物图片、参考图、配音、模型参数、平台接口或自动发布文件。
