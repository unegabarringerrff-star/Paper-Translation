# PaperDrama Skill v3.1｜五档可调戏剧强度 × 首轮一键成稿

**这是一个用于评审的独立 GitHub 分支版本，暂不覆盖 main。**

## 使用方式：现在只需要一次输入
在首次调用 `paperdrama-paper-to-drama` 时提供：
- **论文 PDF**
- **短剧主题**（如悬疑、科幻、喜剧等，可多选）
- **设定**（如重生、系统、灵魂互换、反派主角等）
- **背景**（如校园、现代、宫廷、架空等）

例如直接说：**“用这篇PDF做短剧，主题：悬疑+科幻；设定：系统；背景：校园；戏剧强度：3。”**
可以额外给时长、角色数、**戏剧强度1–5（默认4）**和画幅（默认竖屏9:16 + 横屏16:9）。强度改变的不只是对白强烈程度，还包括论文信息在正片/事实卡/附录的去向和人物、镜头的戏剧化程度。标签参照 references/narrative-library.md，也可以自由发挥。不需要选择A/B/C，不需要输入风格关键词再启动，也无需在中途确认。

如果只提供PDF，没有提供主题/设定/背景且没有授权AI自由发挥，Skill只会**一次性询问所有缺失维度**；如果写“其他你决定”，则自行补齐。

## 五档戏剧强度：论文内容会发生什么变化？

| 档位 | 正片保留什么 | 省略或移到其他地方 | 戏剧/镜头特点 |
|---|---|---|---|
| **1 学术还原** | 问题、方法、主要数据、结论、局限、原文适用的争议/假设 | 重复文献与非必要细节 | 解释清楚、镜头克制，无需强反转 |
| **2 轻度剧情** | 核心方法、主要证据、结论和重要限制 | 长文献综述、重复统计 | 日常人物、小冲突、自然对话 |
| **3 戏剧叙事** | 核心问题、必要方法条件、最重要的证据/结论 | 次要实验/数据到事实卡 | 冲突与调查推动真实发现 |
| **4 强冲突（默认）** | 问题、1–2个关键发现和不可缺少的限定 | 详细方法与次要结果到事实卡/附录 | 高代价、反转、快慢镜头反差 |
| **5 极致架空** | 至少1个真实研究问题/发现及紧邻的结论限定 | 大部分方法与学术讨论放附录 | 奇幻/狗血/悬疑高概念世界，大胆虚构人物与事件 |

高强度的“替换”是将**研究概念的表达形式**替换为虚构行动、角色和世界，不是替换真实研究数据或结论。研究全文事实库始终保存。每次输出 `content_tradeoff_report.md`，逐项说明哪些学术信息进入正片、简化、移至事实卡、附录或不在正片出现。

选择强度可以在第一次输入直接写 `戏剧强度：1` 到 `戏剧强度：5`；若已经生成剧本，直接说“**把现有剧本改成强度2**”，Skill 会复用论文事实库重新编排内容、情节和镜头，而非只换语气。

更多逐类信息：`references/dramatic-intensity.md`。

## 核心改进
1. **取消中途风格推荐**：旧版“分析论文→三套模板→换一波→用户确认→脚本”的路径改成“首轮确定主题、设定、背景→自动完整脚本”。
2. **可选戏剧强度**：1级允许研究过程的完整解释和稳镜头，2级轻度故事，3级证据驱动戏剧，4级默认强冲突，5级高概念娱乐改编。**4–5级**优先3–5秒冷开场、强烈人物代价、视觉反转，低级不再被强制套用。
3. **镜头更像影视作品**：镜头角度/景别/运动承担叙事功能，走位、焦点转移、匹配剪辑、音效、突然静音、视觉意象回收，不是用分镜表机械给论文配插画。
4. **允许大胆虚构**：人物、敌我关系、世界规则、行动与后果可以狗血、荒诞和夸张；允许更少术语和方法细节，但**不可伪造论文核心结果、数字或统计显著性**。虚构故事应显著标注。
5. **一次性输出全集**：full_script.md 具有总集数/各集时长/总时长、全场全镜的完整对白、分镜、音效、双画幅方案以及研究事实溯源。

## 生成管线
输入 PDF + 主题/设定/背景 + 可选强度1–5 → 完整事实库 → **按强度确定保留/压缩/事实卡/附录/虚构隐喻清单** → Drama Blueprint → 按档位调节张力与镜头 → 全集脚本 → 科学真实性/档位一致性/镜头/时长审核 → 全剧成品及内容取舍报告。
