# PaperDrama｜论文到真人竖屏短剧场景生产包

PaperDrama 将可读论文的主要研究机制、发现或核心论证改编为中文真人竖屏短剧。它交付按场景拆分的完整文本，由 MicroDrama 继续提取人物、拆分镜头并生成参考画面。

## 默认行为

- 受众：非本领域大学生，可覆盖。
- 语言：中文，可覆盖。
- 画幅：单一 9:16；其他画幅单独派生。
- 戏剧强度：4级强冲突短剧型，可选 1–5。
- 未给世界、类型或剧情装置时：根据论文自主补齐并记录假设。
- 交付：五份 UTF-8 TXT；03 是唯一默认下游输入。

## 输入示例

“用这篇论文写真人校园短剧，强度4，约三集，每集60秒；不要校园霸凌，保留研究中的关键方法条件。”

也可以只提供论文。Skill 会在不篡改事实的前提下补齐创作设定。

## 不变的事实底线

论文数字、单位、组别、比较对象、结果方向、显著性、因果或相关性质、核心结论和必要限定必须准确。人物、关系、世界和事件可以虚构，但不能伪称论文实验、作者经历或研究已经证明虚构后果。

## 五档强度

| 档位 | 重点 |
|---|---|
| 1 学术还原型 | 用可表演过程清楚呈现必要问题、方法、证据和局限。 |
| 2 轻度剧情型 | 用日常目标和轻冲突帮助理解研究。 |
| 3 证据驱动型 | 让证据改变人物行动和关系。 |
| 4 强冲突短剧型 | 用具体代价、反制和回报推动传播叙事。 |
| 5 极强戏剧型 | 用更尖锐选择和后果推进故事，核心发现或论证必须参与关键转折。 |

强度是完整预设，用户可明确覆盖其中一项，例如保持4级冲突但完整保留关键方法。

## 文件

- SKILL.md：流程和边界。
- references/：事实、强度、故事、交接和检查规则。
- assets/demo-input.md：虚构测试论文。
- tests/acceptance-tests.md：待执行验收规范。

本 skill 不要求外部运行依赖；可选格式校验只用于维护，不能阻断论文转译。
