# PaperDrama Skill v3.0｜从论文到场景级视频生产包

这是用于评审的独立分支版本，不覆盖 main。

## 用途

PaperDrama 从学术论文主要内容中选择一个真实机制，将它发展成有趣、高张力、可表演的短剧，并交付五份 UTF-8 TXT 文件。默认下游会继续提取人物、拆分镜和生成参考画面，因此本 Skill 停在场景级文本剧本，不生成项目资产库、分镜 JSON、模型专用提示词或平台接口。

本 Skill 只由 Markdown 规则文件组成，正常使用不需要安装 Python 包、PyYAML 或运行额外脚本。`quick_validate.py` 仅是维护者可选的格式检查工具，不属于生成流程，缺少它或其依赖不得阻断 Skill 使用。

## 输入

必须提供可读取的论文 PDF。用户可以选填：

- world：青春校园、现代职场、古装架空、近未来、奇幻等；
- genre：轻喜剧、心理悬疑、情感、权谋、冒险、黑色幽默等；
- dramatic_engine：信息差、选择困境、规则试错、身份错位、机制解谜、价值冲突等；
- visual_mode：真人电影感、2D 漫剧、定格、风格化 3D 等；
- premise_device：系统、重生、穿越、循环、读心等；
- 时长、集数、角色、禁忌元素和戏剧强度。

用户已给出的风格轴、时长、集数、角色、画幅、禁忌元素和戏剧强度作为硬约束持续保留；只有与论文事实底线冲突时不执行。缺失项默认由系统根据论文和生产负担补齐，不展示 A/B/C 或中途选择页。

## 论文严谨性与创作自由

必须保持基础数据、结果方向、显著性、因果/相关性质、论文主要内容和必要限定准确。论文机制可以拟人、隐喻和远距离转译；人物、世界、关系、冲突、代价与情节可以大胆虚构，但不能冒充论文实验、作者经历或研究已经证明的现实后果。

事实正确只是底线。成品还必须通过高张力创意绿灯：开场、人物利害、主动对抗、因果升级、反转/回报、新鲜度、视觉叙事和情绪反差。

## 五份交付

输出保存至：

    outputs/<论文文件名>/

只交付：

1. 00_项目与风格说明.txt
2. 01_论文事实与转译边界.txt
3. 02_故事结构与质量结论.txt
4. 03_场景脚本_可直接输入.txt
5. 04_连续性与生成后核对.txt

其中 03 是唯一默认送入下游视频生成流程的文件。每场使用 `E01-S01` 形式的稳定集场 ID，并能够独立复制，包含当前视觉形态适用的角色识别特征、环境、开场状态、按顺序发生的动作与对白、声音、结束状态、必须保留信息、后期精确文字和论文核对备注。关键论文事实无法核验时停在 `BLOCKED_FOR_FACT_REVIEW`，不产出可投产的五份文件。

## 设计来源

本分支结合成熟短剧工作流中可泛化的机制：故事引擎、人物目标与代价、对手反制、场景状态变化、可见动作、对白行动性、连续性、规则分级和定向返工。没有迁移小说专用模板、候选选择、逐阶段人工确认、固定镜长、项目资产库、平台发行策略、供应商协议或模型方言。
