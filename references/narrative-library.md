# 背景与类型模式库

本库帮助解析网页风格参数和补齐缺失创作项。用户已选背景与类型时保留其方向，不生成候选菜单或 A/B/C 选择页。

## 故事背景

- 校园：评价、同伴压力、公开展示、师生权力。
- 职场：权限、资源、责任、绩效和组织决策。
- 都市生活：邻里、平台、消费、亲密关系与公共空间。
- 家庭社区：代际关系、邻里声誉、照护与共同生活。
- 乡村小镇：熟人社会、地方资源、生产生活与传统关系。
- 医疗机构：诊断判断、照护责任、患者与机构资源。
- 科研实验室：研究协作、证据、署名、资源和学术责任。
- 古装架空：证据、名誉、等级、仪式和裁决。
- 近未来：算法治理、身份权限、自动化与技术依赖。
- 星际未来：航行、定居、资源、生命支持和远距离关系。
- 末世世界：资源稀缺、生存协作、秩序崩解与重建。
- 奇幻世界：有边界的超现实规则、代价与选择。

虚构世界不意味着论文研究真的发生在该世界。

## 类型体验

正剧强调处境、选择和后果；悬疑强调证据、误判和揭示；喜剧强调认知落差但不否认事实；情感强调信任、修复和失去；爱情强调亲密关系、试探和承诺；治愈强调后果处理与新常态；成长强调认识、能力或自我理解的变化；励志强调目标、挫折与突破；权谋强调资源、联盟与反制；冒险强调行动目标与风险；惊悚强调威胁、紧迫感和不安。

## 组合原则

背景决定人物处在什么制度、空间和日常规则中；类型决定观众主要感受。一个主背景配一个主类型，论文机制决定人物真正如何行动。

同一类型可在不同背景中有不同表现：校园悬疑靠公开评价与信息差，职场悬疑靠权限与责任，家庭社区情感靠信任与补救，近未来惊悚靠规则和技术依赖。喜剧、爱情与治愈也必须有具体目标和可见行动，不用空泛情绪代替故事。

## 内部叙事引擎

信息差：隐藏 → 误判 → 利用 → 暴露 → 是否公开。
选择困境：两个价值均有代价 → 新条件出现 → 不可逆选择。
规则试错：规则可用 → 例外出现 → 代价 → 修正规则。
机制解谜：异常 → 假解释 → 新证据 → 重构 → 行动验证。
价值冲突：局部利益 → 关系代价 → 制度后果 → 核心选择。
探究协作：疑问 → 分工尝试 → 分歧 → 证据澄清 → 新认识。
关系修复：伤害或误解 → 回避 → 可见补救 → 信任重建。

低强度可以优先探究协作或关系修复；高强度可强化信息差、困境、试错或价值冲突。任何引擎都不能靠角色明明可正常沟通却集体不说话维持。
