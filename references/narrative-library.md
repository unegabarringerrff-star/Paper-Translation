# 短剧四轴模式库

本库帮助解释或补齐风格轴，不是论文事实库、候选菜单或项目资产库。用户原话优先；缺失项由系统内部选择并记录，不向用户展示多套方案。

## World Cards

- 青春校园：身份评价、同伴压力、公开排名、师生权力。
- 现代职场：绩效、权限、资源、责任归属和组织决策。
- 都市生活：邻里、平台、消费、亲密关系与公共空间。
- 古装架空：等级、仪式、证据、名誉、财政和生死裁决。
- 近未来：算法治理、自动化决策、身份权限和技术依赖。
- 奇幻：规则具象化、能力代价、非人角色和象征性世界。

世界卡只提供权力与行动条件，不自动决定类型。

## Genre Cards

- 轻喜剧：认知落差、尴尬、节奏回弹；不能消除真实代价。
- 心理悬疑：不可靠信息、逐层揭露、信任变化。
- 情感：关系选择、信任、失去和修复。
- 权谋：资源、权限、证据、联盟与反制。
- 冒险：行动目标、空间阻碍、风险升级。
- 治愈：后果处理、关系恢复与新常态。
- 黑色幽默：制度与结果的荒诞反差；不得借荒诞改写论文事实。

Genre 规定观看体验，不代替故事引擎。

## Dramatic Engine Cards

### 信息差

- 适配：不同主体掌握不同证据、知识或预测。
- 升级：隐藏 → 误判 → 利用 → 暴露 → 是否公开。
- 风险：角色明明一句话可解释却集体不说。

### 选择困境

- 适配：论文揭示真实权衡或互相竞争的价值。
- 升级：两边都可行 → 新代价显现 → 旧选择伤及关系 → 不可逆决定。
- 风险：一边明显正确，形成假困境。

### 规则试错

- 适配：边界条件、误差、适用范围、失效情形。
- 升级：规则可用 → 出现例外 → 误判代价 → 发现盲区 → 是否改写规则。
- 风险：为反转临时新增规则。

### 误会解除

- 适配：主观体验、错误推断或证据解释差异。
- 升级：误认 → 行动强化 → 反证出现 → 关系重解。
- 风险：只需正常沟通即可解决。

### 身份错位

- 适配：分类、标签、角色判断或权限错配。
- 升级：被错误识别 → 利用错位 → 真身份产生代价 → 选择是否恢复原身份。
- 风险：身份揭露后故事立即结束。

### 机制解谜

- 适配：复杂过程、系统关系或逐层因果。
- 升级：异常 → 假解释 → 新证据 → 机制重构 → 行动验证。
- 风险：角色只站着解释答案。

### 价值冲突

- 适配：效率、公平、自由、安全、准确和体验之间的真实张力。
- 升级：局部利益 → 关系代价 → 制度后果 → 核心价值选择。
- 风险：把反方写成无理由恶人。

## Visual Mode Cards

- 真人电影感：可表演动作、清楚关系、可信空间、自然对白。
- 2D 漫剧：规则与符号可视化，必须仍有姿态、视线和状态变化。
- 定格：物件动作、重复与变形，适合寓言和黑色幽默。
- 风格化 3D：非现实世界和机制奇观，控制群像与复杂交互负担。

## Premise Device Cards

系统、重生、穿越、循环、读心、灵魂互换、预知等是剧情装置。每个装置必须记录：

- 能做什么；
- 不能做什么；
- 使用代价；
- 失效或误判条件；
- 它为主 dramatic_engine 提供什么压力；
- 人物仍需亲自做出的选择。

## 模式卡使用规则

每部作品只取一个主 world、一个主 genre、一个主 dramatic_engine 和一个 visual_mode；必要时各加一个辅助 genre/engine。卡片提供机制，不提供现成角色、场景、道具、台词或剧情。
