# Drama Blueprint｜论文事实到短剧表演的结构化转译（v2.1）

## 1. 输入研究结构
对每个来自原文的学术事实标注：
- `motivation/method/finding/contribution`（KaraokAI 的宽类）
- 研究问题、知识缺口/矛盾、假设/主张、研究行动、证据、结果、局限/贡献/启示等标签（本 Skill 的戏剧适配扩展）
- `fact_id`、论文原文页码/章节/图号、限定词、优先级与证据状态。

## 2. 转译原则（不是机械的章节映射）
| 学术角色 | 可转译的戏剧功能 | 禁止的失真 |
|---|---|---|
| 研究问题 | 人物追问、待解之谜、开局困境 | 把疑问说成已证实结论 |
| 矛盾/知识缺口 | 立场冲突、认知偏差、两种方法之间的选择 | 编造原文没有的研究者争吵 |
| 假设/主张 | 人物计划、赌注或决策 | 把假设演成真实结果 |
| 研究方法 | 调查/验证/行动 | 发明作者没有使用的样本或实验 |
| 证据 | 可视线索、关键物件、数据揭示 | 改动数值与比较方向 |
| 结果 | 后果、揭示、结局 | 无显著变有显著、相关变因果 |
| 局限 | 代价、悬而未决、第二季问题 | 宣称适用于不受支持的人群 |

每一幕可用多项事实、同一个事实可出现在多幕。不是“Introduction=开头，Methods=中间，Results=结尾”的机械结构。

## 3. Drama Blueprint 必填字段
`genre`、`audience`、`world_rules`、`characters`（角色目标/立场/关系与虚构标记）、`central_conflict`、`stakes`、`episode_plan`、`beats`、`emotional_arc`、`performance_rules`（对白、节奏、视觉符号、听觉）、`source_fact_ids` 与 `forbidden_distortions`。
情节节拍可用 Hook→背景事件→对立→行动/验证→证据→结果/澄清→边界；按真实论文和所选剧种适配。

## 4. 方案设计与三个极简选择卡（每次选择新创作路线都要展示）
根据论文事实和 `references/narrative-library.md` 的**主题（28）、设定（42）、背景（11）**标签自由组合，内部生成 A/B/C 三套在叙事机制或观察视角上确实不同的 Blueprint。第四分类“受众：男频/女频”仅为可选内容标签，不覆盖默认学术受众“非本领域大学生”。

**内部详细蓝图**可以包括事实 ID、主要角色、戏剧张力机制、冲突、节拍、剧情、对应证据、剧集数和建议每集时长，并保存到 `drama_blueprints.md`。

**外部展示（含对话和 template_options.md）只能有四个字段：**
```text
A｜《有戏剧张力的剧名》
主题：悬疑、科幻
设定：系统
背景：校园
```
- 恰好展示 A/B/C 三套，每套只有**剧名、主题、设定、背景**；末尾只能请求“请选择 A、B 或 C”。
- 不展示人物、Hook、冲突、具体故事、线索、情节转折、结局、剧集数、时长、评价和推荐；不能将内部蓝图全文贴到初次消息里。
- 标签可多选，允许基于论文需要做合理扩展；历史、奇幻、系统等只用于虚构表演框架，不能宣称研究真的在这些场景发生。
- 剧名要有戏剧张力，但不能通过虚构学术结论制造噱头。
- 模板被用户选定后才产生完整分集脚本，并在镜头层分别适配**9:16竖屏及16:9横屏**。

## 5. 选择后才生成分集脚本
用户选择 A/B/C（或经修改确认）后，才从模板细化 `series_outline` 和逐镜头 `full_script`。改变选项后必须重算角色设定、分集和节拍，不得只替换剧名。

## 6. 集数和时长推导
先数必须让观众理解的独立学术节点与需要演出的关键行动；将内容聚为有独立小高潮的集，再估每集 45–90 秒或另行必要的长度。不能一律固定3集、不能按 PaperTok 的8镜头模板照搬。适当缩减重复讲解而非删掉导致结论不正确的核心条件。

## 7. 事实取舍和演出标注
- `A_CORE`：问题、方法关键条件、结果、限定，不改变。
- `B_COMPRESSIBLE`：次要信息可缩写，保留论文回看入口。
- `C_STAGING`：人物、对话、道具、时间与空间可创造，醒目标记为虚构演绎。
- 无显著结果、方法失败、开放结论可形成真实的“澄清型高潮”；不可假定任何论文都有震撼性反转。
