# 唯一 Drama Blueprint｜事实、机制、故事与交接

## 三层边界

1. fact_invariant：支撑主锚点的不可变事实、来源和必要限定。
2. mechanism_kernel：论文揭示的关系、规则、权衡或边界，用普通语言说明。
3. dramatic_amplification：世界、人物、关系、冲突、代价和回报，明确哪些为虚构。

## 填写合同

### 网页输入合同

- 论文 PDF 与可读范围：
- 故事背景（world）：
- 故事类型（genre）：
- 戏剧强度：
- 用户覆盖项：
- 系统补齐假设：

### 转译合同

- 主锚点及 fact_id：
- 辅助锚点：
- 机制内核：
- 不可修改事实和必要限定：
- 虚构世界规则：
- 虚构内容边界：
- 不可替换性结论：

### 强度合同

- 预设档位：
- 用户覆盖项：
- 实际执行策略：
- 主要事实去向：
- 4级开场问题、行动变化与回报：
- 5级时核心发现或论证如何参与关键选择：

### 分集合同

- 每集目标时长：60–180秒：
- 集数及每集功能：
- 每集开场问题或正在发生的决定：
- 每集回应、状态变化与结尾回报：
- 总故事如何在各集之间递进：

### 故事合同

- 观众承诺：
- 主角当前欲望：
- 主角相关过往经历及其影响：
- 阻力或对手目标：
- 不能拖延的原因：
- 主角优势与代价：
- 行动如何引发回应：
- 关键状态变化：
- 揭露或回报：
- 最终不可逆选择或新常态：

### 人物合同

- 身份、年龄段、外貌和服装：
- 与当前选择有关的过往经历：
- 当前目标与恐惧：
- 惯用策略与能力边界：
- 盲点、底线和改变条件：
- 与其他人物的关系和相互误判：
- 经历如何通过行动、道具或对白显现：
- 本人如何因论文机制改变策略：

### 表演合同

- 人物：身份、目标、关系、弱点和变化。
- 冲突：相反诉求、障碍、升级和选择。
- 情节：起因、行动、意外、结果和后果。
- 情绪：主要节点与反差。
- 表演：动作、停顿、对白策略和空间关系。
- 节奏：每集开场、转折、回报与结尾功能。

原文没有对应的论文成分写 NOT_APPLICABLE；虚构人物履历可自主创作，但必须与真实研究经历分开。
