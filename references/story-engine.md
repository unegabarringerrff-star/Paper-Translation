# 故事引擎｜选择、因果、人物与回报

## 开写前

明确观众承诺、主角想要什么、什么使其不能拖延、阻力保护什么、主角依赖什么优势、使用优势会付出什么，以及论文机制如何改变选择。

为关键人物建立最小但有用的经历链：过去发生过什么，留下了什么判断或伤口；这个判断如何影响当前目标、惯用策略和误判；什么行动或证据能迫使其调整。经历必须服务当前因果，不能只作为装饰性履历。

## 因果循环

压力出现 → 人物按当前策略行动 → 对手、规则或副作用回应 → 信息、关系、资源、风险或情绪改变 → 人物调整策略。

4、5档还要满足：开场钩子可回答或可追踪；人物行动改变局面；回应具有合理来源；场尾给出回报或新压力。高强度要求更具体的利害、反制和代价。低强度也要有可见目标、人物反差或认识变化。

重复吵架、重复羞辱、只提高音量、临时新增规则或无依据反转不构成升级。

## 场景检查

每场回答：

- 为什么现在需要这场？
- 谁在争取什么？
- 什么阻碍当前策略？
- 哪个可见动作或证据造成变化？
- 角色的过往经历如何解释这一选择？
- 场尾交给下一场什么结果、压力或新认识？

安静场景可以处理后果、改变关系、显露证据或形成选择。论文知识应作为行动方法、证据边界、规则限制或价值取舍，而非长篇摘要朗读。
