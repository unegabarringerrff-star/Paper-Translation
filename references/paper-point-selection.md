# 论文转译点选择｜事实底线、锚点与不可替换性

## 事实分层

红区：关键数字、单位、组别、比较对象、结果方向、显著性、因果或相关性质、核心结论与必要边界，不得修改。
黄区：机制、变量关系、方法过程、讨论与局限，可压缩、拟人、隐喻或重排，但不得改变含义。
绿区：人物、关系、世界、冲突、秘密、风险、代价、反转和视觉表现，可自由虚构。

论文作者发现、引用观点和虚构内容必须标明归属。研究没有报告的样本、访谈、争议、作者经历或未来工作不得填造。

## 事实记录

每项主要主张记录：fact_id、来源页码或章节、类型、证据状态、必要限定和重要性。覆盖主要问题、关键方法或条件、主要证据、核心结果或论证、局限；重复表述合并，无关细节按需保存。

研究类型适配：
- 实验或量化研究：如实记录样本、比较、指标、方向与显著性。
- 定性研究：如实记录参与者范围、材料、主题、解释边界，不伪造量化结果。
- 理论或综述研究：如实记录核心论证、前提、反例、适用范围，不伪造实验。
- 设计研究：如实记录设计目标、评价方式、观察结果和限制。

## 主锚点

主锚点必须来自主要研究问题、核心发现、关键机制、重要讨论或主要局限。选择时检查：

1. 中心性：是否属于论文主旨。
2. 转译性：能否成为人物的规则、资源、信息、选择或后果。
3. 利害：人物会得到、失去、误判或必须取舍什么。
4. 可见性：能否落实为动作、道具、空间或关系变化。
5. 生产性：能否在真人竖屏场景中清楚呈现。
6. 真实性：不需要改动红区才成立。

写出转译链：论文事实或关系 → 机制内核 → 世界规则 → 人物欲望与阻力 → 选择、代价和结果。

## 不可替换性测试

将主论文机制替换为无关概念。若关键选择、主要转折和结局仍不需改变，论文只是装饰，应重做锚点或转译。不是要求每场讲论文，而是要求故事关键因果依赖它。

不显著、失败、矛盾或证据不足可以成为证据悬疑、规则盲区、信念修正或继续行动的困境；不得改写为论文取得显著成功。
