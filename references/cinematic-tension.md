# 高张力场景引擎

## 基础立场

短剧首先是行动叙事。论文提供真实机制、证据边界和价值张力；人物、世界、对手、关系与后果负责把它变成戏。严谨性不能把故事写成论文朗读，趣味性也不能修改数据和结论。

## 高张力最低要求

1. **开场已经发生事**：异常结果、冲突、危险、身份错位或人物决定正在发生；不先交代研究背景。
2. **人物有可失去之物**：信任、尊严、资源、关系、自由、位置或生命必须具体。
3. **行动造成下一问题**：因为 A，人物做 B；B 引发 C；C 迫使更昂贵的 D。
4. **对手会学习**：看到主角的能力、证据或策略后改变反制方法。
5. **转折改变状态**：至少改变信息、权力、关系、资源、风险、情绪或物理状态。
6. **先兑现再留问题**：交付一部分能力、证据、关系或情绪回报，再由结果打开下一压力。

高张力不等于全程争吵、奔跑或快速剪辑。安静的决定、物件交接、停顿和距离变化也可以承载高压。

## 场景张力单元

每场规划：

- scene_goal：本场不可替代的剧情目的。
- protagonist_goal：主角现在要什么。
- opponent_goal：对手或规则保护什么。
- obstacle：什么阻止当前策略。
- action：主角采取的可见行动。
- counteraction：对手、规则或副作用如何回应。
- state_change：本场改变了什么。
- price_or_payoff：付出代价或兑现什么。
- outgoing_pressure：向下一场交付什么。
- source_fact_ids：本场实际承载的论文事实。
- fiction_label：虚构范围。

无新信息、无关系变化、无局势变化且不处理后果的场景删除或合并。

## 表演与对白

- 把心理写成注视对象、手部选择、重心、距离、呼吸、停顿或道具处理。
- 对白用于争取、回避、试探、威胁、交换、证明或重新定义关系。
- 机制已由动作演清后，对白不再重复解释。
- 一个人连续讲述时，用对手的行动、反应或新的证据改变其策略；不要仅为“有动作”插入无意义表情。
- 论文术语只在关键事实必须被准确说出时进入对白，其余移到核对备注或后期图层。

## 声音

声音服务行动：脚步、门响、纸张、呼吸、环境底噪、静默和声音桥。音乐在证据、笑点、呼吸和权力转折处让路。场景动作修改后，相关声景同步修改。

## 竖屏表现

重要人物、手部动作和关键物件集中在竖向注意区域，减少依赖横向群像和整面复杂图表。只写观众必须看到什么，不替下游规定具体景别、运镜或剪辑。

## 失败模式

- 用感叹号和大声台词假装升级。
- 反派重复同一种羞辱。
- 主角等待系统或权力人物代打。
- 为反转临时加入新规则、新资源或新亲属。
- 长篇解释论文，动作只是站着听。
- 每场都用同一种钩子或强度，造成疲劳。
- 精确数字依赖生成画面里的纸张、屏幕或白板。

## 改写顺序

故事平淡时依次检查：人物会失去什么 → 对手如何主动反制 → 行动是否造成新问题 → 论文机制是否进入关键选择 → 是否已经兑现部分承诺。不要先增加运镜和视觉形容词。
