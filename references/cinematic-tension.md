# 电影化短剧张力引擎｜PaperDrama v3.0

## 基础立场
短剧首先是具有代价、转折和情感欲望的**行动叙事**，论文知识是冲突的因果与证据材料。允许夸张反派、誓言、背叛、追逐、荒诞规则、时间压力、空间反差；它们属于虚构故事。不能将伪造的数据、统计显著性、实际论文作者经历和实验活动伪装成来源事实。

## 六级戏剧强度机制（默认强度4/5）
1. **视觉冷开场**：前3–5秒先发生事——重要物品被销毁、倒计时失控、关系破裂、身份揭露或一个极强行动，不从“本研究旨在...”开始。必须与后面的故事逻辑有关。
2. **具体欲望与代价**：每个主要角色既有想得到的东西，又有最怕失去的东西（信任/尊严/资源/关系/自由/生命等）。把抽象矛盾变成当下必须做的决定。
3. **因果升级**：事件A导致尝试B，B诱发副作用C，C迫使代价更高的选择D。不能只堆叠三次吵架或三个无关反转。
4. **权力与认知逆转**：用证据重新解释前一幕、令弱者暂时占上风、令胜利付出代价；反转首先改变人物地位或观众认知，不篡改论文真实结论。
5. **情绪反差**：高强度冲突与短暂停顿/脆弱时刻交替，恐惧之后给一秒幽默、确信之后给怀疑、胜利之后出现代价，避免平铺的持续高分贝。
6. **集尾悬念**：悬念应是具体待解决行动/关系/真实尚未解答的问题，不用故弄玄虚的“未完待续”或凭空公布夸大数据。

## 逐场景可拍摄的“张力单元”
每个场景内部至少记录：scene_goal、opponent_goal、obstacle、action、counteraction、reversal_or_price、emotional_shift、source_fact_ids、fiction_label。
**无新信息、无关系变化、无局势变化的场景直接删掉或并入。**
不必强制每集多次反转，但每集必须完成一项可见局势改变与一个情绪释放点。

## 镜头语法：镜头为信息和权力服务
| 场面功能 | 有表现力的镜头策略 | 容易失败的写法 |
|---|---|---|
| 开场危险/异常 | 特写局部动作→突然拉开现实关系；或主观镜头看见异样 | 三行旁白交代背景 |
| 角色立场对立 | 景别从双人中景逐步收紧，视线轴和遮挡表现距离 | 人人永远面对镜头朗读 |
| 掌握线索 | 遮挡→揭示；视线接物件插入；焦点从人物转给证物 | 用旁白无情绪播报研究表格 |
| 逆转局势 | 低角度/高角度权力位置互换、反打节奏突变、匹配剪辑 | 直接让角色喊“反转了！” |
| 危险决定 | 手部微动作、停顿、极近景与环境远景的交错 | 镜头标注“推近”，毫无原因 |
| 结果与代价 | 视觉母题回收：同一物件与第一集前呼后应，音画反差 | 只出现论文总结幻灯片 |

**视觉分层**：每镜描述前景/主体/背景、可见动作、视线和运动方向，重要信息让观众“看见”而非全靠台词。镜头参数不能自动堆满；有时固定镜头+5秒沉默比连续推拉更有力。
**转场**：交代 cut / match cut / whip pan / sound bridge / hard cut / silence 的选择和因果动机；避免每镜都堆特效。
**9:16**：特写、单人纵深调度、道具/字卡纵向安全区；**16:9**：群像、空间对抗、前后景关系与双人轴线。不能仅写裁切尺寸。
**声音**：具体SFX、环境噪声、音桥、顿止、节奏点；重要句可停BGM。选用可获得/可合成的音效而不依赖昂贵动作场面。

## 对白演出规则
- **潜台词优先**：人物说的是策略，真正要的是欲望；有打断、反问、停顿、动作对白和后果。
- **尽量让冲突呈现在一段动作里**，不是以学术演讲解释“冲突是什么”。
- 故事夸张可用“所有人都背叛了他”的虚构叙事事实，但不能说“论文证实所有用户都被骗”。
- 正式数据和样本条件在少量关键桥段/屏内研究事实卡中点到为止；不过度灌输术语。

## 强度等级
1 克制讲述；2 轻剧情；3 明确人物冲突；4 **默认：激烈冲突、强画面、代价升级、人物情感反差**；5 极度狗血/奇幻/讽刺，仍保留论文事实底线。使用用户明确的强度优先。

## 内部评分与重写
对每集 opening_hook、goals_and_stakes、causal_escalation、reversal_or_cost、emotional_contrast、cliffhanger、visual_storytelling、shot_purpose、sound_design 和 format_adaptation 打0–5启发式分数。关键项（goals_and_stakes、causal_escalation、visual_storytelling、shot_purpose）低于4先重写；不把自评分当外部实验结果。注意不要为了评分做毫无关联的夸张镜头。
