# 分集与场景级剧本写作

## 写作顺序

事实与内容去向 → 网页风格参数 → 唯一蓝图 → 故事因果 → 分集时长 → 分集分场 → 开场状态、动作、对白和结束状态 → 时间与连续性检查。

默认写完整故事和全部台词，停在场景级。不要输出镜头表、分镜JSON或“后续AI补齐”。

## 分集时长

- 每集目标时长必须在 60–180 秒之间。
- 时长包括自然朗读、动作、停顿、反应和后期文字阅读；核对备注不计入播放时长。
- 集数根据故事完整性、因果推进和每集可独立理解的功能自行决定。
- 每集至少形成一个完整推进单元：目标受到阻碍，人物采取行动，局面发生变化。
- 非终集可以留下下一集压力，但本集必须对当前问题作出部分回应；终集完成主要故事的关键兑现。
- 发现单集超时时，先删除重复、压缩解释、让行动承担信息或重组完整动作单元；仍超时则重新分集，不得默默延长。
- 发现单集过短时，合并相关动作或场景，不用重复争吵、重复说明或无关事件填充。

## 每场

使用 scene-handoff.md 的唯一模板。每场有明确的剧情目的，并改变信息、关系、权力、风险、情绪或物理状态之一。必要时按完整动作或对话单元拆分，不按固定秒数机械切场。

## 开场与持续吸引

4、5档每集尽快呈现具体异常、正在发生的决定、已出现的结果、关系异常或目标受阻。中段必须有行动回应与状态变化；结尾给出本集回报、部分揭示或新的可理解压力。钩子应来自人物和论文机制，不靠无依据的灾难或临时反转。

## 人物与对白

关键人物需要有与当前选择相关的过往经历、当前目标、惯用策略、能力边界、盲点、底线和改变条件。过往经历优先通过现在的动作、道具、关系反应或有指向的对白显现；只有确实改变观众理解时才使用回忆。

动作必须可见或可听。关键道具写清起始持有人、交接和结束落点。人物对白格式为：姓名（语气、语言）：“实际台词。”旁白无则写“无”。

对白应争取、回避、试探、交换、证明、拒绝或改变关系。不要让人物说双方都已知道的信息。研究术语只在准确表达必须出现时进入对白；其余可由行动、后期文字或核对备注承担。

## 时间

先估算自然朗读，再给动作、停顿、反应和字幕阅读留出空间。台词、动作和反应可并行时可合理重叠，不能假定所有复杂动作都能同时完成。时长不足时按完整单元压缩或拆分；只有用户明确锁定时长时才保持其锁定值，未锁定时遵守每集60–180秒范围。

## 事实

剧中实际说出的研究断言关联 fact_id。数字、单位、术语和公式需要逐字正确时，进入后期字幕或图层内容；正文只预留合理载体。必要限定应在相应断言附近实际出现，不能只留在核对备注。
