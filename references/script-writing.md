# 场景级剧本写作

## 写作顺序

事实与内容去向 → 唯一蓝图 → 故事因果 → 分集分场 → 开场状态、动作、对白和结束状态 → 时间与连续性检查。

默认写完整故事和全部台词，停在场景级。不要输出镜头表、分镜JSON或“后续AI补齐”。

## 每场

使用 scene-handoff.md 的唯一模板。每场有明确的剧情目的，并改变信息、关系、权力、风险、情绪或物理状态之一。必要时按完整动作或对话单元拆分，不按固定秒数机械切场。

## 动作与对白

动作必须可见或可听。关键道具写清起始持有人、交接和结束落点。人物对白格式为：姓名（语气、语言）：“实际台词。”旁白无则写“无”。

对白应争取、回避、试探、交换、证明、拒绝或改变关系。不要让人物说双方都已知道的信息。研究术语只在准确表达必须出现时进入对白；其余可由行动、后期文字或核对备注承担。

## 时间

先估算自然朗读，再给动作、停顿、反应和字幕阅读留出空间。台词、动作和反应可并行时可合理重叠，不能假定所有复杂动作都能同时完成。时长不足时：删除重复、让动作承担信息、缩短台词、按完整单元拆场；只有用户未锁定时长时才调整规划时长。

## 事实

剧中实际说出的研究断言关联 fact_id。数字、单位、术语和公式需要逐字正确时，进入后期字幕或图层内容；正文只预留合理载体。必要限定应在相应断言附近实际出现，不能只留在核对备注。
