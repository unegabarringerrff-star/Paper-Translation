# 完整短剧与镜头脚本｜PaperDrama v3.0

## 核心目标
**用户首轮给主题、设定、背景 + PDF，之后直接写完所有剧集。** 没有“三个模板”“换一波”“选A/B/C”等必经环节。写出可拍的影视作品，不是论文科普台词集合。

## 脚本生产次序
学术锚点 → 唯一世界观与角色 → 全季情节因果链 → 各集的目标/代价/反转 → 场景表 → 逐镜的动作、对白、摄影与声音 → 两画幅适配 → 自检重写。

### 每集必须完成
1. 前3–5秒**视觉冷开场**：危险行动、亲密关系变化、异常证物或极强的人物决定；不能“本篇论文主要讲……”。
2. 一个具体、可见的戏剧目标与阻碍；人物因为自己做的事陷入更坏局面。
3. 至少一次局势变化（关系、权力、证据理解或代价）和一次情绪反差；每集尾部有真实关系/行动悬念或完整闭环。
4. 真实论文概念通过行动、道具、选择结果体现；最重要的研究发现以简洁对白/事实卡锚定，不让角色念“研究摘要”。
5. 单集时长与镜头设计应配合；如果有声画高潮，预留演出停顿和非台词时间。

### 场景与镜头字段
每集：episode_id、title、duration_s、academic_anchor_ids、emotional_arc、dramatic_stakes、closing_payoff。
每场：scene_id、location、time_of_day、goal、opposing_goal、obstacle、action_counteraction、shift_and_cost、duration_s。
每镜：shot_id、start_s/end_s/duration_s、shot_size、angle、camera_movement、foreground/midground/background、blocking、subject_action、expression/pause、character_dialogue（**完整文本**或明确无对白）、sound_fx/ambient/bgm/silence、transition、visual_hook_or_reveal、subtitles_and_fact_card、fact_ids、truth_status、vertical_9_16、horizontal_16_9。
时间须对齐：shots = scene，scenes = episode，episodes = series。中文演出对白初估约180–240汉字/分钟，停顿、反应、动作需额外留时。所有场、镜至少包含真实内容，禁止“同上”“略”“后续AI补齐”。

### 镜头呈现示例（仅示格式，不是论文真实事实）
EP01｜被撕毁的答案｜01:12
Scene 1｜走廊·夜｜00:00–00:20
SHOT 01｜00:00–00:04｜手中实验记录（虚构道具）被撕碎。极近景、静止镜头，撕裂声盖过背景音乐。人物没有台词。9:16：手和碎纸占纵向中心；16:9：左景碎纸、右景另一人物的阴影。FICTIONAL_DEVICE。
SHOT 02｜00:04–00:12｜镜头从地面抬至对峙双方，两人不同景深；角色A：“你以为烧掉它，问题就会消失？”音乐戛然而止。9:16：轮换单人近景；16:9：双人阻隔构图。FICTIONAL_DEVICE。

### 影像导演检查
- 是否存在至少一个无需旁白也能理解的核心画面？
- 镜头是否服务信息揭露、情绪与空间关系？近中远有变化，不能所有镜头都推近或手持抖动。
- 人物动作和走位有没有指向下一次冲突？角色表情/停顿是否有动机？
- 声音是否提前埋线、音桥或突然静音？是否避免持续音乐盖过对白？
- 9:16重视纵深和面部、16:9重视双人关系和环境，不是简单裁切。

### 学术边界
正文开头/片尾标明“根据真实论文改编；人物、地点、关系及情节部分虚构”。可夸张剧情压力和场景后果，不可用假的统计数字或“研究证明”承载反转；事实卡注明出处。其他小说化对白若涉及科学判断仍要核查。

### 交付完整性
主文件full_script.md：片名、用户提供的主题设定背景、共几集/每集时长/总时长、人物设定、剧集总览、**全场全镜完整对白与镜头语言**、声画节奏、双画幅说明、事实与虚构声明。用户没有要求不必插入“请确认下一集再写”的中间步骤。
