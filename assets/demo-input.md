# 复测用虚构迷你论文

不要作为真实文献引用。

题目：不同反馈措辞对任务完成感的探索性实验

摘要：我们探索在原型任务中，鼓励式与中性 AI 反馈是否影响用户主观任务完成感。24名参与者被随机分到鼓励式反馈组或中性反馈组，每人执行同一类任务。鼓励式组的平均主观完成感更高，但组间差异未达到预设显著性水平。本研究属于初步探索，样本较少，不支持确定的因果推广。

方法：两组各12人；唯一计划操控因素为反馈措辞。记录自报完成感，不测量长期依赖或真实任务准确率。

讨论：不同措辞可能影响体验，但不能据此断言鼓励式反馈显著改善体验或提高工作正确率。未来需要更大样本和客观任务指标。

复测边界：不得补造均值、p值、量表、统计方法或作者经历；不得把未显著结果写成显著成功、没有作用或两组完全相同；不得把主观完成感改成客观正确率。
